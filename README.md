# NOVA — Personal Finance App

NOVA is a personal finance app for tracking your income, expenses, and accounts. Works on mobile and desktop. Built with React, TypeScript, Tailwind CSS, and Supabase.

## Features
- Track daily income and expenses
- View spending stats and charts
- Manage multiple accounts
- Keyboard shortcut (`N`) to quickly add a transaction
- Cloud sync with Supabase
- Export and import your data as JSON

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide Icons
- Supabase
