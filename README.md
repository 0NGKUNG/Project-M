# N∅VA — Sovereign Personal Wealth & Capital Protocol

N∅VA is a border-free, high-performance personal finance app designed for mobile speed and desktop productivity. Built with React, TypeScript, Tailwind CSS, and Supabase.

## Features
- **Typographic Dark Aesthetic**: Elevated `#101014` cards on deep `#060608` sovereign dark background.
- **Physical Keyboard Support**: Type amounts on desktop/laptop numpads, use `N` key shortcut anywhere to open quick transaction modal.
- **Supabase Cloud Sync & Security**: Real-time storage with strict owner-only authentication.
- **Local Fallback & Backup**: Export/restore private JSON data anytime without vendor lock-in.
- **Account & Budget Analytics**: Filter transactions by account, track monthly category limits, and view spending breakdown charts.

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
- Supabase Client
