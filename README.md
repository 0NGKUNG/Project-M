# ∅ NullVault — Sovereign Personal Finance Tracker

NullVault is a border-free, high-performance personal finance app designed for mobile speed and desktop productivity. Built with React, TypeScript, Tailwind CSS, and Supabase.

## Features
- **Responsive Dark Theme**: Elevated `#101014` cards on deep `#060608` background.
- **Physical Keyboard Support**: Type amounts on desktop/laptop numpads, use `N` key shortcut anywhere to open quick transaction modal.
- **Supabase Cloud Sync**: Real-time storage with PostgreSQL schema and RLS policies.
- **Local Fallback & Backup**: Export/restore private JSON data anytime without vendor lock-in.
- **Account & Budget Analytics**: Filter transactions by account, track monthly category limits, and view spending breakdown charts.

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
- Supabase Client
